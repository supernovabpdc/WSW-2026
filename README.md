# WSW 2026 Hackathon: Prototype Submissions

**Deadline:** Monday, 2 Nov 2026, 11:59 PM (GST)

## How to submit
1. Prepare your submission:
   - **Data/software prototype:** push it to your own public GitHub repo with a README (problem, solution, tech stack, how to run).
   - **CAD model:** put your CAD files and a few renders/screenshots in a Google Drive folder set to "Anyone with the link can view".
2. Go to the **Issues** tab here, click **New issue**, and choose **Prototype Submission**.
3. Fill in the form and submit. One issue per team.

Judging uses the last commit (or Drive file version) made before the deadline.
